# Bundled fonts

Google Sans Code is used for source code, inline code, code gutters, walkthrough source, and console output. The interface retains JetBrains Mono; KaTeX retains its mathematical fonts.

The unmodified Google Sans Code variable Roman and Italic TTFs were downloaded on 29 October 2026 from the official Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/googlesanscode
- Upstream project: https://github.com/googlefonts/googlesans-code
- License: `OFL-GoogleSansCode.txt`
- Upstream naming guidance: `TRADEMARKS-GoogleSansCode.md`
- Roman SHA-256: `c9649573afcd966f61096b1e9c3c3115e7b54315ca2adf9839c6f8b17d5f8e1f`
- Italic SHA-256: `bdf116292f27aca16e2aefb5534042a25f244d3a9187a521ce97fc2117a4a844`

Fonts are served from the app bundle and require no external font requests. Monaco remeasures character widths after the code font loads. JetBrains Mono's existing license is in `OFL-JetBrainsMono.txt`.
